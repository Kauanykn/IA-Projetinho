# Stack técnica

## Base

- React para a interface.
- TypeScript como linguagem principal.
- Node.js para serviços de backend.
- SQLite como banco de dados provisório.

## Diretrizes

- Manter uma stack popular baseada em TypeScript.
- Implementar autenticação para permitir o cadastro de notícias.
- Exibir as notícias cadastradas na página inicial.
- Tratar SQLite como escolha inicial, sujeita a revisão conforme as necessidades do projeto.
- Priorizar navegadores modernos e layouts compatíveis com dispositivos móveis.
